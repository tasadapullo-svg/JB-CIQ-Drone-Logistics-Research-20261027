# V2.1 必须加入真实求解器的单元、集成与科学核验测试

## 1. 阶段级离线真数据预检
- 输入溯源/校验值SHA256一致；QGIS图层真正引用解析成功；坐标范围/ID/跨区边界正确。
- 冻结订单ID唯一、日期与研究区域合法；三模式共享同一需求集合；历史5日与新增全部日期不可混总量。
- 道路有向路由合法、转弯/禁行检查；旧37例只当候选；开关边界等待不影响MY境内任务。

## 2. 物理守恒
- 同一辆车的里程 sum(links)=trip.distance；油耗由燃油计量/模型产生，不能把共享路段分给两单后再汇总两次。
- 无人机航次去程、返程/回收、悬停与储备约束一致：E_flight <= usable_battery - reserve；电表购电 kWh >=电池放电kWh/eta（若充电效率已记录），不得由机型标称最大航程直接反推每公里kWh。
- 雨风停飞的任务仍在服务率分母里：已回退则真实送达时间/汽油消耗均记录；若未完成则状态失败，耗时不能=0。
- 收到 `kgCO2/TJ` 的燃油因子不许直接乘 L，必须单位换算且燃料密度、NCV与年份来源明确。
- WTT/WTW 因子不允许跟 TTW 因子重复相加；两国电网因子不许跨国错用；未经气体口径统一不得把CO2和CO2e加为CO2e。

## 3. 非预期优势检测
- 纯汽油路由的车辆路线优化质量须与混合模式可比；试验“无无人机可用”时 M1/M2 的油耗、服务能力不能无缘无故优于强M0。
- 充电损耗提高、无人机飞行绕行距离增加、汽油额外接驳增加，其他条件固定时混合模式的能源使用/排放应有可解释的响应。
- 当风超过宣称的情景禁飞阈值、UAV电池不足或站点不合规，系统必须拒绝对应UAV任务，执行兜底或未完成。
- 运行同一随机种子与环境，应得相同原始输出SHA（浮点误差、线程调度除外；须固定容差与排序）。

## 4. SCI统计验收
- 按独立随机seed配对订单需求；按真实日期块控制环境自相关；报告 n_seed、n_unique_day、n_unique_weather_grid 和订单行数，不能混称样本量。
- 混合模式结果同时报告全任务完成率、准时率、门到门时间的共同完成订单效应及全任务成本/排放账。
- 低碳优化在服务/准时/成本上限满足时才返回FEASIBLE；无可行解可返回INFEASIBLE及冲突约束清单。
- 置信区间覆盖抽样随机性、参数区间与日期变动；严格区分三者。

## 5. 最小科学算例（供手工核算，不是研究结果）
- 两订单同一路线共享车辆1条车次：订单账可分别分摊，但系统车次公里仅计一次。
- M1仅1单成功飞行另1单回退：该订单保留总分母、燃油和飞行/充电共计，送达截止时间按真实模拟事件判断。
- 100%禁飞日：所有计划无人机订单拒绝发飞，模式的额外地面/等待/设施开销仍然纳入，不可只返回已成功飞行的样本。
- 跨境排队50分钟的测试情景：只影响跨境道路事件，不影响两个境内OD。数字仅为测试输入，不是真实排队观测。
