# V5 S07 GitHub 原始数值验收：本次执行决定

**研究主线不变**：汽油车 M0 对比 DJI FlyCart 30 和 Wingcopter 198 Cargo 参与的 M1（固定站点混合）、M2（动态车机协同）。所有模式共享 V5 冻结空间和合成任务；最终检验服务质量、成本、运营碳排放及最低碳可行条件。

## 新修复的关键问题

1. 前版本 S07 使用“14 个文件全部 PASS”作为统一硬门槛，其中包括 29,842 条历史 Stage 6 订单、两 CIQ 历史 E03 气象 CSV 和汇总包；不应使它们成为**新版 V5 82,620 条冻结订单**的强制计算前提。本版改为 6 份核心天气/FCD、4 份历史 A/B 路网、4 份辅助参考分别检查。
2. 真实单元测试发现最初的时间转换器误将合法 ISO `+08:00` / `Z` 时区标记为无效；已修复并用 UTC→MYT 跨日实例验证。
3. 天气 Excel 的 `ERA5_Hourly` 每月历史声明 4 条额外记录，本程序真实读取时将列出这些时间戳及身份；它们可能是累计降雨边界时刻，但在核验前不能宣布其原因，也不能静默删除。
4. 新增 GitHub Actions 入口：同仓库固定历史提交读取全部原始字节并执行逐行检查，从而规避 ChatGPT 当前容器不允许外部 DNS 的限制。**工具已本地测试，远程 runner 尚未执行。**

## 当前事实与阻断

- 本地冻结 ZIP 真实哈希 PASS。68 节点和任务分组原样保留。
- 14 份大型源文件仍未在当前容器挂载，无法复算原始天气、FCD、OSM 的实际数值。此处不能标记 PASS。
- 历史 QA 报告称 FCD 1,266,840 条（345×3,672），速度缺失 125,230，非正值 55；这仍是**历史报告记录**，本次未复算这些原件。
- 历史 A/B OSM 分别有 178,098 和 104,317 条有向边；C 区、转向、国界排除和站点地面入口未验收。
- 天气仅返回 2 个不同的 ERA5 网格中心；B/C 区空间代表性问题已在上一阶段量化，必须在后续敏感性实验中保留。
