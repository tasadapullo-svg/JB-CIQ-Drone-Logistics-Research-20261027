## 在联网 Windows 环境继续
1. 解压本 ZIP 到本地新目录，不改动原始 V5 文件。
2. 安装 Python 3.11+ 与可选依赖：`python -m pip install -r requirements_optional.txt`。
3. 双击 `RUN_WINDOWS.cmd`，或先逐条运行其包含的命令。下载来源固定到 GitHub 提交 `4569817b8145efe2ae06f4b21addc1986f971c12`。
4. 将下载/运行生成的完整目录打包回传。即使成功下载也必须核对 SHA、工作表、时区与单位、V5 道路入口、转弯限制，再放行。
