## 为什么要分成 4,590 组？

30 种子是同一研究设计的重复模拟世界；不同种子或日期绝不能把任务拼成同一条真实车辆路线。所有 M0/M1/M2 的成本和排放都必须先在对应种子×日期的物理车次上求和，再比较同场景差值。不能将 82,620 条合成任务当成 82,620 条独立实测证据。

## S08 / S09 / S10 接口契约

1. `run_id`：同一天同一随机种子的独立仿真实例，不与其他 `run_id` 共享车队与车辆里程。
2. `task_set_sha256`：五种模式必须完全一致，否则拒绝比较。
3. `routing_status`：目前 `HOLD_UNVERIFIED_DIRECTED_ROAD`。真实 M0 与 M1/M2 地面车辆都必须使用同一经验证道路图，不能用 UAV 直线替代。
4. `weather_status`：目前 `HOLD_UNVERIFIED_HOURLY_WEATHER`。无人机在真实调度的起飞/着陆/返回时间重新查表。
5. `operation_emission_status`：目前 `NOT_COMPUTED`。汽油车排放按实际物理车次计一次；无人机飞行与充电分别有源标定，避免重复记账。
6. `M0` 汽油车、`M1_DJI`、`M1_WING`、`M2_DJI`、`M2_WING` 的任务分母一致；不适合飞行的包裹应由车辆执行或按模型规则列明未完成，而非删除。
7. 非实测订单、粗空间气象代理和历史 OSM 不得声称真实企业运营结果。
