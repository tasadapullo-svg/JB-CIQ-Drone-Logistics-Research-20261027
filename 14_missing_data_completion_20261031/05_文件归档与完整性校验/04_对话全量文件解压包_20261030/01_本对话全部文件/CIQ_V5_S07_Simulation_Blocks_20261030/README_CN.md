- V5 原始地图与 68 节点清单原样保留，不增删修改任何节点。
- 已核对 82,620 个冻结合成任务的时间、分区、节点经纬度、唯一 ID、重量和状态。
- 30 个种子 × 153 个自然日 = **4,590 个独立种子–日期仿真块**；每块 18 单，A、B、C 各 6 单。
- 5 种模式共 **22,950 个应运行的模式块**。每块携带相同的 `task_set_sha256`，防止混淆任务基准。

## 本地完整执行入口

将 ZIP 解压至独立目录，安装 Python 3.11+，然后运行 `RUN_WINDOWS_S07.cmd`。此脚本将按 GitHub 固定提交恢复已登记的 11 个历史文件、验证哈希、读取 XLSX 的 `Weather_Hourly` 原始表，并尝试获得覆盖 V5 全区的当前 OSM 有向驾驶网络。需联网以及 `osmnx>=2,<3` 等依赖。

外部来源即使下载成功也**不自动取得运营放行资格**；必须进一步验收气象单位与累计窗口、实际有向可达、场地进出口、转向、速度数据、共享车辆资源、油耗及无人机载重能耗模型。

原始 ZIP 和 82,620 条订单不会被下载程序修改；本包是完整的输入配对与恢复工具，不包含虚构的道路或碳排放结果。
