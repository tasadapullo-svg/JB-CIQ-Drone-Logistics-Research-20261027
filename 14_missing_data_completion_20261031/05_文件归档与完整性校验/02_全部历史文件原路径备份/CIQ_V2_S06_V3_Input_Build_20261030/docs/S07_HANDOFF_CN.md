# 给 V2-S07 的正式数据交接（有条件）

已具备：`node_id`、WGS84 经纬度、三分区和港区扩展标签，候选 UAV 与地面关系的**不相混用**编码，69 节点/116+5 连接 GeoJSON。

S07 必须执行：

1. 对 2026 年 5–9 月小时气象时间序列与 `node_id/zone` 空间映射，记录 ERA5 四参考点落入两个网格、NASA POWER 格网与气象变量差异。不得把四个参考点等同四个独立站点。
2. 接入实际 OSM 有向可路由道路图；道路距离与车辆时间从网络图生成。最小出入口审计应记录节点到可进入道路的距离、道路方向和可达性。对旧 37 个问题 OD，不允许自动按“已修复”放行。
3. 统一合成订单标识、时间区、投送/回程和三模式一致性。必须保留旧 19 节点的跨版本坐标复核门槛，或者显式使用新生成订单而不偷换历史样本。
4. 在正式订单计算前形成可追踪的源哈希、覆盖率、异常记录与 release gates。地面路由、天气及无人机能耗都未闭合时，不得计算新版碳减排率。

此交接仅批准 **REFERENCED_SPATIAL_JOIN**，不批准 **ACTUAL_OPERATIONAL_ROUTING**。在假设性且明确标注场景边界的仿真中，可以继续推进模型开发，避免把项目变成实际飞行许可申请。
