## 4. 预先冻结的速度统计方法
对节点i的开发期2026年5—7月正值观测速度计算 `V_i,P90,train`。对于任意时间t：`r_i,t = V_i,t / V_i,P90,train`（无量纲），缺失时不进行补值。
输出的月份—小时档案将2026年5—9月的节点小时速度/比值汇总为p10、中位数、p90，同时给出正值覆盖率与预期节点小时数量。2026年8—9月不参加P90基线拟合，避免开发/评估泄漏。
这些统计量**不是**道路边的逐小时车速，也不是OD旅行时间；其输出文件名明确标注`NO_EDGE_MAPPING`。

## 5. E02 正式动态旅行时间：必要的计算逻辑（本轮尚未执行）
有向边e长度 L_e[m]，若在进入该边的时间t_e取得经批准的车速 v_e(t_e)[km/h]，理论无等待行驶分钟数：`Δt_e = 0.06 × L_e / v_e(t_e)`。随后将当前时刻更新至 `t_e+Δt_e` 再检索下一条边；不可对全程统一使用出发时刻的道路速度。
正式完成时间还应加转向、停车、接驳/装卸等服务时间，并按法规和法定国境限制筛选路径。对数据未观测的边允许设置明确标记的模型补全策略，但其覆盖比率必须报告；不应将缺失值默认为0或畅通。

## 6. E02仅剩的有限验收工作（不扩大128参考OD集合）
1. **FCD→定向OSM边**：复核道路名、实际车道/方向、地理距离与原始路段坐标；把通过审核的记录填入 `08_manual_directed_edge_approval_TEMPLATE.csv`，证明文件编号保存，不以最近道路自动批量通过。
2. **交通合法性**：补齐OSM turn-restriction关系、马来西亚境内边界与可用连接路口；集中核对A05、B02、B07的真实车辆出入口。
3. **车辆OD验证**：将128参考OD筛为真正需要的物流OD（其余保留初筛清单），用独立导航/行程样本填写 `09_independent_OD_time_validation_TEMPLATE.csv`，在模型冻结前定义验证样本和误差判定口径。
4. **最终赋速并算路径**：生成边—小时记录，保留OBSERVED_DIRECTION_VERIFIED、MODEL_IMPUTED、UNKNOWN三种证据状态；按实证覆盖分层报告时间，完成独立QA后才能标记E02正式验收。
