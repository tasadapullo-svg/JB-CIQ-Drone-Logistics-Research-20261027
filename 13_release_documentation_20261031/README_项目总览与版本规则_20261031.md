# CIQ 无人机物流 SCI 项目总览与版本规则

## 版本结论

- **正式研究版本起点：2026年10月30日。**
- 10月30日重新设计的飞行区域、研究点位和明确禁飞区，以及据此重新制作的 QGIS 工程和正式实验结果，是论文理论研究与实证分析的正式依据。
- 10月29日及以前形成的第一版方案、实验、图表和审查材料，仅作为研究基础论证与方法演进记录，不得直接替代10月30日正式版本的结果。
- 10月31日形成的实验闭环、最小证据集及后续验证，是10月30日正式研究路线的延续，不属于旧版。

## 一级目录

1. `01_最终版实验结果_20261030`：正式 QGIS、S07-S11 实验、10月31日闭环与证据集。
2. `02_正式论文与理论说明`：正式版本定位、理论研究说明及后续正式论文文件。
3. `03_正式研究基础数据与工具`：交通、GIS、天气、文献、代码和原始数据。
4. `04_历史实验与基础论证_截至20261029`：第一版及其他历史实验，仅作基础论证。
5. `05_文件归档与完整性校验`：历史原路径、压缩包、重复副本和 SHA256 校验材料。

## 文件使用顺序

论文写作和结果引用时，先使用 `01_最终版实验结果_20261030`，再结合 `02_正式论文与理论说明`。只有在说明前期研究基础、方案演进或补充溯源时，才查阅 `04_历史实验与基础论证_截至20261029`。

## 2026年10月31日新增论文收口材料

`02_正式论文与理论说明` 已加入以下正式工作文件：

- `SCI论文全文收口总控稿_20261031.md`：论文定位、研究问题、结果边界、章节结构与主结果冻结说明；属于研究与写作底稿，不等同于已完成投稿稿件。
- `SCI论文图表证据索引_20261031.csv`：图表、研究问题与证据来源的对应关系。
- `SCI论文理论来源起始表_20261031.csv`：理论、方法与监管来源的起始清单，后续仍需逐条完成引用核验。
- `SCI论文全文收口材料包_20261031.zip`：上述收口材料的交付包。

这些材料属于10月30日正式研究路线的论文收口更新，不属于10月29日前的历史基础论证。

## 目录层级规则

用户可见的整理结构控制为“一级分类 + 二级内容”两层。QGIS 工程、代码工程和可复现实验包内部保留其原有技术结构，以避免脚本、数据依赖和工程相对路径失效。
