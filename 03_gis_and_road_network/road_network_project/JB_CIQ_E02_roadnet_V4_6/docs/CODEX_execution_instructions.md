# 给Codex的工作指令：E02，只运行已冻结的研究范围

你正在执行 Johor Bahru 双CIQ 地空协同物流 SCI 的 E02（真实有向道路交通网络）阶段。仅限A：Causeway与B：Second Link，使用现有345节点注册表以及19条参考地理位置。不要重做2026年9月FCD数据源的审计；该问题已在V4.2/V4.3记录。气象数据由另一条流程处理。

1. 在本工程安装 `requirements.txt`，执行预检与合成单行线单元测试。
2. 从OSM Overpass获取A和B的原生有向道路数据，保留OSM下载JSON、实际请求时间、下载源、SHA256以及道路标签。若被限流，按照错误处理重试；仍失败时清晰记载阻塞，不以直线样本点构建伪道路。
3. 严格区分实际OSM路网与研究作者提供的FCD观察点；道路几何匹配需要路名和方向外部证据；未知方向不得自动赋值；OSM分类参考车速不能声称是FCD实测车速。
4. 根据 `code/e02_roadnet.py` 生成两个区域有向边CSV、原生路网GeoJSON、FCD最近边候选清单、站点接入检查及128个参考方向对的初步OD估算。原始CIQ两个背景参照点不自动视为车站或实际物流订单。
5. 再增加正式成果所需的马来西亚法定边界裁剪/边境道路排除、OSM转弯限制校核、方向匹配人工验收、独立导航旅行时间检验，才允许把状态从 `MODEL_ROUTE_REQUIRES_QA` 改为 `OBSERVATION_CALIBRATED`。若证据未到位不要硬改。
6. 输出每项QA通过数/异常数、无法连通的OD方向对、图层与路由数据的SHA256以及独立复核结果；按A/B分文件，保持可复算。

最终向用户报告实际道路下载数量、通过的OD、尚未通过的证据门槛，并打包ZIP留档。不添加新研究区域、新订单类别、新模型或额外实验组合。
