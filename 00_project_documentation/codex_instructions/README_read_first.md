# E05 V5.6 三十随机种子模拟需求稳健性审查

这是对V5.5 **已冻结的30,600单示范性订单**进行**分层有放回重采样**，并不是独立校准后的真实订单生成机制。

- 30次种子：20261027—20261056。固定每个`month × area × demand_class`单元的订单数，每次总计30,600条；总计918,000条抽样记录。
- 对原订单整行重采样，保留其真实观测的小时FCD与ERA5联结；不拼接不对应的时间和天气。一个原订单可能被抽中多次；这是重采样而非实际需求观测。
- 按独立CSV逐次保存详细样本，冻结原30,600单源文件在V5.5归档中。本包提供源文件SHA256。
- 输出覆盖率、OSM**未验证模型代理**时间的存在率、3/4 km**几何**可达比例、天气暴露比例。没有正式车辆OD时间、无人机批准航段、能源/成本参数，**不计算节时、成本或净CO₂e收益**。
- 30次2.5%—97.5%分位数是种子变化的**经验区间，不是因果效应置信区间**，也不包含模型参数或现实需求结构的不确定性。
- 该重采样保持月/地区/订单类别总量，但不保证每次每个日期和时刻都有订单；全天24小时的交通和天气底层数据库仍保留153天×24小时。需要按天固定需求时应另用事先声明的条件生成模型。
- 配对交通模式对照时每个seed的同一张订单表必须复用于纯地面、固定多节点和车机协同方案，不得分别重抽。
- 匹配数据不是合法飞行许可；夜间天气异常保留，无法取得许可的任务须设为无法放行/地面兜底。

后续正式成果放行需要：合法场站/航线和夜航情景假设的法律边界、真实OD车辆模型独立验证、机型与能源/成本排放参数以及本地需求情景范围的外部证据。
