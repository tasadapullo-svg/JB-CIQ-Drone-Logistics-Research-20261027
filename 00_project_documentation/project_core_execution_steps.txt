## 二、将正式实验压缩为三个阶段

## 01

空间网络可行性实验

固定两个研究区、3/4 km半径和候选设施准入标准。

只回答三个问题：哪些真实站点可用、哪些节点之间能形成可行航段、能够覆盖多少目标物流需求。

输出：2张GIS研究区图、1张站点可行性表、1张网络连接及覆盖分析表。

## 02

交通—多式联运效率实验

使用相同的真实交通时间、订单与道路网络，比较纯地面、固定航网和车辆协同方案。

重点验证物流网络对拥堵路段、配送时间、订单完成率及车辆行驶里程的影响。

输出：分时段效率比较、模式适用性、3/4 km覆盖差异。

## 03

天气—碳排放综合评价实验

在第二阶段已固定的网络上加入同期实际天气，评估无人机停飞、地面兜底、服务可靠性与净碳排放。

同时完成三机型的有限横向对照，不为某一机型单独改变订单或交通条件。

输出：净减排结果、天气适用性、三机型比较及最终综合决策。

## 四、明确实验什么时候结束

我建议设置五条正式停止规则：

1. 数据冻结： GIS候选节点、交通观测、气象数据、需求生成规则和机型参数在正式运行前确定版本。
2. 模型冻结： 目标函数、约束、算法参数、对照策略和随机种子在最终测试前确定。
3. 验证冻结： 预先区分模型开发数据与最终评价数据，避免用最终结果反复调参。可暂定5—7月为开发期、8—9月为评价期，待9月数据语义检查完成后一次确定。
4. 统计停止： 主要结果统一报告效应量、95%置信区间和预先确定的检验方法，不因为未显著而继续增加实验。
5. 结果停止： 当预先规定的实验矩阵全部完成、数据及代码审计通过后停止新增实验；只有发现实质性计算错误或审稿人提出必要的有效性问题，才通过记录修订理由的方式开展补充实验。

对于仿真订单，如果使用随机生成机制，应事先冻结样本生成规则与随机种子集合，不在观察结果后选择表现更好的样本。

## 五、最后必须形成的 SCI 论文结果

| 研究问题              | 主要结果证据                  |
| ----------------- | ----------------------- |
| RQ1：多节点物流网络在哪里可行？ | 合法候选站点、可行航段、实际订单覆盖      |
| RQ2：何时比地面配送更有效？   | 分时段总交付时间、准时率、可替代车辆里程    |
| RQ3：能否真正降低环境影响？   | 同等订单完成条件下的CO₂e、成本及天气可靠性 |

最终结论可以是某种模式更好，也可以是某一口岸不适合大规模无人机配送，或者共享D2订单不能明显提高经济性。这些都是可以报告的科学结果。

特别需要强调：不以无人机必须产生正向收益作为实验成功条件，而以能否得到可靠、可复现、具有明确适用边界的结论作为成功条件。

## 六、对后续研究文件的统一规定

今后的每份实验资料都应增加一张固定的 Experimental Boundary and Freeze Record（实验边界与冻结记录），至少包含：数据版本、研究区域、研究假设、输入参数、实验组、对照组、评价指标、重复次数、模型冻结时间、排除规则和完成状态。

这张表一旦冻结，任何新增实验都必须明确属于错误修正、预注册敏感性分析还是独立的未来研究，不能随意并入主实验。

最终采用的研究原则是：研究范围有限、变量有依据、实验组合固定、统计标准统一、负面结果保留、达到验收标准即结束。

这样，后续工作就不是不断增加 GIS 图和仿真结果，而是围绕一套固定证据链完成一篇目标明确的 Sustainability SCI 论文。

我的最终建议
我倾向于采用升级后的研究主线，但建议设置明确的研究决策关口。

如果 F0–F1 能够形成可信证据，并且 LC-M1 的效果能够通过独立情景验证，那么新版研究在方法与应用贡献上更有竞争力。

如果真实机型能耗或空间条件无法可靠核实，那么原来的“可行性—效率—碳排放权衡”路线反而更适合作为主论文，LC-M1 可以保留为探索性扩展，而不是强行成为核心贡献。
最终研究定位
我建议采用这一句话作为整篇论文的核心定位：
本研究针对马来西亚柔佛新山的交通、气象、空间及燃油配送特征，构建可行性与可靠性感知的低碳地空协同物流决策框架，识别无人机配送的适用条件，并在同等服务和经济约束下评估其相对于传统地面配送的净运营减排与部署策略。

最终判断：新版更值得推进，但不应该推倒原来的研究。 原来 G01–G12 的仿真、统计、经济核算和帕累托实验全部继续服务于三个 RQ；新增的 LC-M1 只承担最后一步“如何主动选择低碳模式”的创新任务。
