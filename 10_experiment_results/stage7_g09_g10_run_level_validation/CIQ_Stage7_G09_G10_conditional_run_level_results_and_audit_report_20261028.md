## 4. G09 与 G10 的关键物理边界
1. **天气判定时刻**：在计划无人机离地分钟而非订单释放小时检查 ERA5 的该小时天气。19:00 是模型假定的操作截止时间，**不是马来西亚法规普遍规定的起飞禁令**。
2. **回退路径**：对预计不满足起飞条件的订单，在本轮重仿真开始前取消转运方案，从订单源头执行地面配送。这是采用计划出发天气的先知式预判，不模拟已经进入 B 区批次干线后的临时撤回。
3. **摩托车车型分配**：根据独立订单 ID 的 SHA-256 确定性分配 40%/40%/20% 的摩托/1.6/1.8 假设占比。模拟仍共享原先起点车辆资源槽，不是带固定摩托与轿车数量的物理异质车队。M2 仍限定轿车执行双包裹会合。
4. **载重与体积**：原需求包裹均为 0.2–2.0 kg。Honda Vario 125 车主手册的储物舱最大行李重量约 10 kg；仅凭重量不会触发该阈值，但**没有货物体积和骑手负载信息**，不能证明这些订单实际均能由同类摩托车运载。
5. **摩托车速度**：0.8/1.0/1.2 是以已有汽车道路旅行时间为代理的倍率压力测试，未根据 JB 摩托车探针速度标定；路线长度保持源数据。
6. **货运柴油车辆**：B 区共享干线单列 10 L/100km 柴油假设，不代表特定 Toyota Hiace 官方认证油耗。
7. **经济性与碳边界**：计算运营期燃油燃烧 CO2e + 无人机电力 CO2e；不含上游燃料制造、设备生产全寿命。保留未经验证的非燃料资源费用。

## 5. 对论文主线的意义

在燃油汽车对照下，部分地空协同方案有运营减排空间，但往往需要更高经济成本；在摩托车参与的地面配送基准下，减排结论可能反向，尤其是要求汽车维持双订单会合的 M2。
因此论文核心解释变量不仅是无人机功率和天气，更包括**谁被替代（125cc 摩托、1.6L/1.8L 汽车还是柴油货运车）**、运输网络层级和车辆运营成本。
