# CIQ Stage 6 — 研究结果与模型边界

## 数据与模型
- 使用冻结30个随机种子，每种子5个固定日期，共29,842条既有合成订单；三个模式各保留一条，共89,526条记录。
- 与 Stage 5 不同，本轮 M0 也重新计算：道路代理采用订单释放小时的有效FCD比率（固定用于该任务的后续行驶），不跨日期合成新的实时观察。两轮数值不能直接混作同一基准。
- A区M1：来源地→站点→无人机去回；B区M1：来源地→集货节点→共享批量干线→前置站点→无人机送达并返回站点。
- M2：货车在地面轨迹上的候选地点起飞，途中无人机送第一单，与同车的第二单会合；车辆旅行及无人机回收占用同一车辆。
- 去程带载、返程空载；ERA5 10m 风向与风速投影为顺/逆/侧风，修正地速、分钟与kWh；数值系数是情景假设，不代表任何特定机型。
- 所有费用、电耗、单位日设施排放都是尚未校准的测试情景。仅电网因子采用马来西亚能源委员会2024年半岛暂定值0.740 kg CO2e/kWh，不是2026年实测。
- 91条有模型路径的OD及有效小时代理参与服务评价；没有的被三个模式同时保留为不可评价，不能记作已服务或删除。

## B区批量转运
- B区M1共创建489个路由批次，输送726票无人机订单，平均每车次1.48票；在本抽样需求下共配载率低，固定成本不能被摊薄。
- B02/B07没有被伪造为已连通地面场站。任何可飞节点只是候选参考点，未获得实际起降许可。

## 同服务边界与统计
- 600个按种子×日期×区域×候选模式的配对服务检查均通过。
- 成本和排放可在相同已完成订单数量下作为模型条件情景总量比较，但不应表述为实际运营净减排。
- 30种子的bootstrap区间仅覆盖合成随机抽样差异，不能覆盖道路代理、站点可行性和机型能耗的不确定性。

## 后续缺口（不阻碍当前条件情景报告）
- 无人机电池、质量、载重曲线与功率须由明确机型资料或飞行测量标定。
- 仍需验证候选场站实际进入、土地、空域、建筑障碍、起降安全条件。
- 道路代理仅具有内部一致性，无法据此宣称峰时实际通行与节时效益。
- 多级批量运输需要研究真正的整车路径优化、跨批次资源重排与在途风时变，目前是FCFS及贪婪路线选择。
- 未包含贸易通关：现有OD完全位于马来西亚境内CIQ周边。
