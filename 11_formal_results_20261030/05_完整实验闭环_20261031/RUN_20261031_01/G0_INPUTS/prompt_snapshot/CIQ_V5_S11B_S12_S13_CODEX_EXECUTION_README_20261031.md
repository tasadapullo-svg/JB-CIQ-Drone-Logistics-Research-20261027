# S11B → S12 → S13：Codex 全实验执行包说明

## 1. 使用方式

1. 在当前包中打开 `CIQ_V5_S11B_S12_S13_SCI_ALL_EXPERIMENTS_CODEX_MASTER_PROMPT_20261031.txt`。
2. 在 Windows 本地 Codex 中将工作目录设置为：`C:\Users\DELL\Desktop\CIQ 无人机物流 SCI 研_20261026`。
3. 全选并粘贴 TXT 的全文，不要只粘贴 README 或 S11B 旧版 Prompt。
4. 确保历史 S07–S11 工程、V5 GIS 工程、冻结订单、天气/FCD 文件可被 Codex 在工作目录或关联目录下找到。
5. Codex 只应写入 `output_SCI_Complete_Experimental_Closure_20261031\RUN_...`。无法完成的关卡必须留 `HOLD` 或 `NOT_RUN`。

## 2. 研究主线

CIQ 周边 A/B/C 三分区的合成物流需求，在相同服务约束下对比汽油车 M0、固定站混合 M1、移动协同 M2，以及 DJI FlyCart 30 / Wingcopter 198 Cargo；主要评价技术可行任务、配送服务、运营能源排放代理、运营成本和有约束的最低碳方案。

本工程**不是**实际获批跨境飞行或实测减排项目；S11 的严格空间天气结论应保留为初始条件性发现。在硬缺陷修复及真实重算完成之前，不得冻结最终 SCI Results。
