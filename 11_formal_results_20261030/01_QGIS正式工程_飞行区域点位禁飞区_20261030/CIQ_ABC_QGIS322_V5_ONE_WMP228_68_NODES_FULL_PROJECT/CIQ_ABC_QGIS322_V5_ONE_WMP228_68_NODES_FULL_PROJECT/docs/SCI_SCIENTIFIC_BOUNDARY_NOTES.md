# V5 scientific boundary and evidence limits

- Only the **CAAS_2026 WMP228 2 NM reference disc** is visible. This is a visual/reference selection following user request, not a claim that it supersedes Malaysia's current legally effective AIP.
- The CAAM AIP text in 2025 gives center `012845N 1034433E`, while the CAAS 2026 reference in the original V4 project uses `012845N 1034334E`. This inconsistency must be resolved using current primary-source CAAM AIRAC AIP, amendments and NOTAM before deployment modeling.
- Both sources describe a southern boundary coincident with the South Johor coast. V5 keeps a single **full-circle** proxy, explicitly NOT a reconstructed legal no-fly polygon. The shoreline and border were not surveyed or derived here.
- A/C boundaries are **illustrative cartographic research envelopes**. Clipping is performed against a selected 2026 2 NM circular proxy with +160 m margin so those *display envelopes* do not overlap it. This does not make any air operation legal.
- A_N10 was removed from V5 active layers per user instruction. It had no incident edge in the supplied 111+10 geometric links. Original values are preserved in archive for reproducibility.
- Inter-area connection lines are preserved as a separate layer (OFF by default) because they should not be spuriously assigned to an area group; 121 original geometric candidates remain in active V5 and an additional four ground-only HOLD reference lines are retained OFF by default.
- Node and edge placement does not imply permitted UAV pads or approved routes. No claims of regulatory clearance, meteorological feasibility or verified CO2e savings are made.
- QGIS validation still pending actual QGIS 3.22.4 GUI execution.
